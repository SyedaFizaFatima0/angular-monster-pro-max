# Nebula Angularダッシュボード ⚡

データ駆動型アプリケーションのためのコマンドセンター——明確さと高性能が融合する場所です。

Nebulaは、Monster Angular Liteの洗練されたアーキテクチャから着想を得たエンタープライズ向けAngularダッシュボードテンプレートです。Monsterが包括的な管理機能を提供するのに対し、Nebulaは現代のWebアプリケーション向けに**リアルタイムデータ可視化、モジュラー型コンポーネント設計、および適応型インテリジェンス**に焦点を当てています。Angular 18とBootstrap 5をベースに構築され、TypeScriptのstrictモードに最適化されているこのテンプレートにより、開発者は一切の設定負荷なしで分析用ダッシュボードや監視パネル、SaaSバックエンドを構築することができます。

# 厳格な制約事項
1. **構造の維持**：元のMarkdownのデータ構造、インデント、見出し階層、表、リンク、URL、バッジ、コードブロック、インラインコードを一切変更しないこと。
2. **選択的翻訳**：ユーザーに表示される可視的な自然言語コンテンツのみを翻訳すること。
3. **変更禁止**：コードタグ、キー名、変数プレースホルダー（{{var}}、${var}、%s、%dなど）、コマンド例、ファイルパス、プロジェクト名、API名、パッケージ名、モデル名、識別子、コード記号を翻訳または変更することは**厳禁**である。背景情報に既に対応する訳名が記載されている場合を除く。
4. 用語、スタイル、固有名詞の翻訳は、提供された背景情報と一致させること。

## 概要 🌌

Nebulaは単なる管理パネルではありません——それはデータのための**視覚的なオペレーティングシステム**なのです。まるで宇宙船のコックピットのように、あらゆる計器やチャート、操作パネルが即座に理解し、迅速に対応できるように設計されています。サーバーの指標や財務フロー、ユーザーエンゲージメントの追跡に関わらず、Nebulaは生の数値を実用的な洞察に変換してくれます。

このテンプレートは「目に見えないフレームワーク」という考え方を採用しており、その基盤となるアーキテクチャが非常にしっかりと構築されているため、ユーザーは一切苦労することがありません。コンポーネントは分離されており、ステート管理も予測可能で、Bootstrap 5の最新バージョンに基づくCSSユーティリティシステムによって、スタイルを上書きすることなくピクセル単位の精密なカスタマイズが可能です。

## コア機能 🚀

### 🔬 リアルタイムデータエンジン
Nebulaには事前に構築されたWebSocket統合レイヤーが搭載されており、ページを再読み込みすることなくチャートやテーブル、ウィジェットを更新します。同梱されている`DataStreamService`が自動的に再接続、バッファリング、スロットリングの処理を行います。

### 🧩 モジュラー型コンポーネントアーキテクチャ
データテーブルから通知トーストに至るまで、すべてのUI要素が独立したAngularモジュールとして実装されています。必要なものだけをインポートすればよく、ツリーシェイキングに対応したこのパターンにより、モノリシックな管理用テンプレートと比較してバンドルサイズを最大**40％**削減できます。

### 🌐 多言語対応インターフェース
英語、スペイン語、フランス語、ドイツ語、日本語、アラビア語（右から左への表示）に対応したJSONベースの翻訳ファイルを備え、初期状態から完全な**i18nサポート**が実現されています。`TranslationGuard`によりルート変更時に言語パックが事前読み込みされるため、切り替え時の遅延も一切ありません。

### 📊 柔軟なチャートシステム
NebulaはChart.js 4をカスタムラッパーと組み合わせており、ビューポートのサイズやデバイスのピクセル比率に応じて自動的にチャートの解像度を調整します。モバイル端末では棒グラフがドーナツチャートに変形し、タブレット端末では散布図のツールチップの精度が向上します。

### 🛡️ 企業向けグレードの認証機能
JWTトークンのシミュレーションを備えたモック認証フロー、ロールベースのアクセス制御（Admin、Editor、Viewer）、およびルートガードが搭載されています。`AuthStateService`はAngularのsignal APIを利用して反応型の権限チェックを行います。

### ⚡ パフォーマンス制限
各コンポーネントは以下の機能により事前最適化されています：
- `OnPush`変更検出戦略
- アイテム数が100件を超えるリスト向けの仮想スクロール
- 非同期で読み込まれる機能モジュール
- CDNリソース向けのプリコネクトヒント

## アーキテクチャ上の決定事項 🏗️

- **ステート管理**: NebulaはAngularのsignalsと軽量なストアパターン（内部ではRxJSの`BehaviorSubject`を使用）を組み合わせており、NgRxやAkitaの依存関係は一切不要です。
- **スタイリング手法**: Bootstrap 5のクラスを活用したユーティリティファーストCSSに、Sass変数やカスタムCSSカスタムプロパティが追加されています。_nebula-theme.scssファイルを使えば、300以上のデザイントークンをオーバーライドできます。
- **ルーティング**: 機能モジュールはラージーロード機能付きのサブルーティングを採用しています。シェルレイアウト（サイドバー＋ナビゲーションバー）は事前に読み込まれ、コンテンツモジュールは必要に応じて逐次読み込まれます。

## カスタマイズガイド 🎛️

### テーマ変数
```scss
// _nebula-theme.scss（一部例）
$nebula-primary: #6C5CE7;      // メインアクセント色
$nebula-surface: #1E1E2E;      // カードの背景色
$nebula-text: #CDD6F4;         // テキスト色
$nebula-border-radius: 12px;   // 角丸半径
$nebula-transition: 0.3s cubic-bezier(0.4, 0, 0.2, 1);
```

### 新規ルートの追加
1. `src/app/features/` 内に新しいコンポーネントを作成します。
2. レイジーロードを実現するために、`loadComponent` を使用してそのルートを `src/app/app.routes.ts` に追加します。
3. `src/app/layout/sidebar/navigation.ts` にナビゲーションリンクを追加します。

### チャートライブラリの拡張
Nebulaはプラグインベースのチャートシステムを採用しています：
- 新しいチャート実装を`src/app/shared/charts/`に配置します
- `ChartRegistryService`内の`registerChart(name, factory)`メソッドを使用してそれを登録します
- テンプレート内では`<nebula-chart type="yourChartName">`ディレクティブを通じて利用します
